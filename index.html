Before you download

  • No GitHub account needed for downloads. Qualified binaries and language packs will be hosted in the public CosmosBuild-Downloads release repository.
  • Choose your languages on first launch. JavaScript is bundled. Optional .NET, Java, Rust, Go and Python packs download separately and are verified before use.
  • Extract-and-run, not MSI installation. Keep the EXE with the rest of the extracted folder. Additional languages can be selected from the app's tray menu.
  • Quit the existing app from its tray menu before upgrading. Projects are stored separately from the installed application.
  • The current target is at least 8 GB RAM; 16 GB and hardware virtualization are recommended. Low-powered PC performance is not yet qualified. Startup and compilation can be slow. Setup checks disk space for the selected languages.
  • GitHub Copilot access and an internet connection are required for AI generation. Windows may show an unrecognized-publisher warning for this unsigned preview.

A few things worth knowing

Simple on the outside. Clear about the details.

Do I need to know how to code?

No coding is required to describe an app, review its plan, or use the preview. This is still a prototype: complex requirements, organizational policies and production readiness can need developer or administrator help.

Is everything on my computer?

Files, the local preview and test execution are local. AI requests go to GitHub Copilot, source backups go to GitHub, and publishing creates resources in your Azure subscription. An installed app is not an offline AI model.

What does it cost?

Copilot generation uses your GitHub Copilot allowance. Publishing may create paid Azure resources, and repository workflows may use GitHub Actions. You review deployment separately. No price estimate is implied by installing the preview.

What gets backed up?

Source code and engineering documents, not database contents or credentials. In the current source version, the default is a few key checkpoints. You can choose more frequent draft backups or only tested versions using Backup settings.

Can I move on without CosmosBuild?

Yes. Download the source or clone your GitHub repository. A developer can work on the conventional application and its deployment assets. Automatic merging of edits made outside CosmosBuild is not implemented; divergent changes are not silently overwritten.

Which apps can it build today?

The development version supports JavaScript, Java, .NET, Go, Rust and Python, with Azure App Service and Cosmos DB. It does not promise every framework, arbitrary hosting target, or production-ready multi-user permissions. Review the generated assumptions and tests.

Where is the GitHub Pages site?

This public site is hosted from CosmosBuild-Downloads. The application source repository remains private. ZIP and language-pack downloads will be published only after their release checks pass.
